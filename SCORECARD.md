# OpenSSF Scorecard Governance State

The repository implements Scorecard-oriented controls including least-privilege workflow permissions, immutable action references, CODEOWNERS, dependency automation, security policy, and workflow-risk checks.

The GitHub-hosted OpenSSF Scorecard action was attempted during release validation but its external container image could not be pulled in the current GitHub runner environment because the upstream registry required billing. The Control Layer therefore records this as **HOLD / NOT VERIFIED** rather than fabricating a score.

This is consistent with the hierarchy: uncertainty is HOLD; authority is not bypassed; evidence is not promoted beyond what was actually verified.
