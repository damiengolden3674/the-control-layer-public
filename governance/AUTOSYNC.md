# Control Layer Automatic Synchronization

Human > Control Layer > Control AI > Governed Executor > Ecosystem/OS.

`governance/profile.json` is the canonical public profile contract. Verified state changes may update the website, GitHub evidence and resume artifact automatically.

Automation is bounded: it may update factual presentation and evidence, but it may not change secrets, access control, billing, human authority, governance ceilings, destructive actions, certification claims, or private trust-spine material. Uncertainty => HOLD; ambiguity/material risk => ESCALATE.

No fallback telemetry may be represented as live. Every automatic public update must record source state, generated time and integrity evidence.
