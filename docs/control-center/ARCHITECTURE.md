# Control Layer Eagles Control Center

A governed multi-view Home Assistant control surface for an always-on Android wall panel.

## Hierarchy
Human > strongest available AI > The Control Layer > Control AI > Governed Executor > ecosystem/OS/services.

## Views
- Command: real-time home + security overview
- Security: firewall, fail2ban, Tailscale, SSH, verification
- Infrastructure: Pi resources, Docker, HA, Homebridge, Matter, observability
- Network: Tailscale and Pi-hole/DNS
- Smart Home: canonical device control
- Data / Observability: logs, traces, DNS and host telemetry
- Control / AI: governance state and proof
- Career / GRC: governance evidence and professional learning surface
- Ambient / Screensaver: always-on branded display
- Charging: dedicated charging state
- Proof: live verification

## Governance
EXECUTE only when validated and authorized. HOLD on uncertainty. ESCALATE on ambiguity/risk. DEFER/SIMULATE for non-production. No blind destructive recovery or automatic approval.

## Telemetry
Host and security telemetry is exposed locally to Home Assistant. Loki and Tempo provide log/trace observability; Pi-hole provides DNS security telemetry; Tailscale provides the secure remote-access boundary.

This document intentionally contains no private IPs, credentials, tokens, or personal identifiers.
